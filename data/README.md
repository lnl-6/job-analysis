# data/ —— 数据目录说明

## 目录约定

```
data/
├── raw/
│   ├── boss_岗位数据集.csv     # 适配后的分析数据集（本地生成，**不入库**）
│   └── boss/                   # 抓取的原始 JSONL + 采集清单（本地生成，**不入库**）
└── published/                  # 可公开入库的聚合统计（78 行 × 13 列，不含岗位级字段）
```

> **仓库不携带任何数据文件**：Git 只跟踪 `published/` 的聚合表。
> 真实数据集与原始抓取结果都留在本地（`.gitignore` 已排除）。

## 数据来源（使用数据时必须登记）

- 来源：Boss 直聘公开搜索结果接口（`wapi/zpgeek/search/joblist.json`）
- 关键词：数据分析；城市：47 个城市；采集时间：2026-11-14；条数：2021 条原始记录
- 合规：低频 20s/请求、只取搜索列表字段、不采集招聘者个人信息、原始响应不入库
- 发布范围：只提交聚合统计（`published/boss_market_summary.csv`），单个岗位与公司名不入库

## 怎么得到数据集

```bash
# 现场抓取（需要登录后的 Cookie；抓完自动适配成分析 CSV）
python scripts/crawl_boss.py --cookie-file cookie.txt --query 数据分析 --to-csv
```

产出 `data/raw/boss_岗位数据集.csv`，之后 `python main.py` 分析的就是它。
测试不需要数据文件：`tests/_fixtures.py` 现场造夹具（CI 也用它生成临时数据集）。

## 字段说明（7 列分析契约）

分析数据集必须包含以下 7 列（列名完全一致，含空格与标点）：

| 字段 | 必需 | 类型 | 岗位口径的含义 | 允许值 |
|---|---|---|---|---|
| 学历 | ✅ | 分类 | 岗位要求的学历 | 大专 / 本科 / 硕士 / 博士 / 不限 |
| 专业 | ✅ | 分类 | 岗位方向（适配层归类） | 数据分析 / 数据开发 / 算法 / 数据治理 / 数据产品 / 其他 |
| 期望薪资 | ✅ | 数值 | 岗位薪资区间中值（元/月，面议留空后按中位数填充并留痕） | > 0（非正值视为无效记录，清洗时剔除） |
| 满意度评分 | ✅ | 数值 | 岗位吸引力**代理分**（0~5，不是满意度） | 0 – 5 |
| 是否有实习经历 | ✅ | 分类 | 岗位是否面向实习/应届 | 是 / 否 |
| 毕业去向 | ✅ | 分类 | 岗位类型 | 实习 / 校招 / 社招 |
| 工作城市 | ✅ | 分类 | 岗位工作城市（占位值统计时排除） | 城市名 / 无 |

> 放好数据后先跑 `python main.py --check-data` 验证列名和类型。

## 数据加载顺序

`src/loader.py` 只有一个默认数据源：`data/raw/boss_岗位数据集.csv`。
其他任何 CSV（外部数据、旧数据集）都不参与自动探测，需要时用
`python main.py --data <路径>` 显式指定。

## 本仓库对「结果」的态度

- 程序内不存放任何预设结论或预测；报告里每个数字都来自当次运行，并带数据指纹与参数记录。
- README 不复述任何一次运行的具体数字（有测试守着），避免出现与数据脱钩的「预设结论」。
- 样本量低于 `config.MIN_GROUP_SIZE`（默认 30）的分组不给差异结论；交叉分析中样本不足的组合直接留空。
